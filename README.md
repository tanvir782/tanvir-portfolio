# Tanvir Ahmed — Portfolio

A responsive, static personal portfolio built with HTML, CSS, and vanilla JavaScript. It is ready to deploy on Vercel or GitHub Pages.

## Run locally

Open `index.html` in your browser, or run a local server from this directory:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy to Vercel

1. Create a GitHub repository (for example, `tanvir-portfolio`).
2. Upload the contents of this folder to the repository root.
3. In Vercel, choose **Add New → Project** and import the repository.
4. Keep the Framework Preset as **Other**. No build command or output directory is required.
5. Click **Deploy**.

The CV and profile image are stored in `assets/` and are referenced with relative paths.
